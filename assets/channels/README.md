# شعارات القنوات

ملفات SVG منتقاة من Simple Icons 16.38.0، محفوظة محليًا دون اعتماد CDN وقت التشغيل. المصدر https://github.com/simple-icons/simple-icons والمكتبة تحت CC0-1.0؛ حقوق العلامات والشعارات منفصلة، وتفاصيل المصدر والترخيص الفردي إن وُجد في sources.json. تُستخدم للتعريف بالخدمات ولا تعني شراكة أو اتصالًا مفعّلًا. شكل المسارات محفوظ؛ أُضيف fill للعرض على سطح أبيض. gbp يستخدم علامة Google لتعريف عائلة ملف النشاط وليس شعار منتج مستقلًا.
